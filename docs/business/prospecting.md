# Prospecting & Verification Manual

## Objective
Identify high-ticket clinics (Dental, Cosmetic Surgery, Orthodontics, MedSpas) losing after-hours enquiries, verify their current intake gaps, and prepare tailored demonstrations.

## ICP (Ideal Customer Profile)
- Independent high-end cosmetic practices (3 to 15 chairs/providers).
- Average treatment value between $2,500 and $20,000.
- Actively running local PPC (Google Ads, Meta) or local SEO campaigns.
- In-office hours restricted to 8am - 5pm weekdays.

## 4-Step Verification Process ($0 Capital)
1. **After-Hours Website Audit**: Visit website after 6:30 PM.
2. **Contact Flow Inspection**: Check if visitors only see a static multi-field web form.
3. **Speed to Lead Test**: Submit a test inquiry asking for Invisalign or Veneer pricing. Measure time to human reply.
4. **Log in LeadFlow AI Prospect CRM**: Record verified observations into `/admin/prospects`. Mark any unobserved metric as UNKNOWN.
